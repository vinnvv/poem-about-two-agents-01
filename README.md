## Run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt`.

## The poem

Two agents never meet. The first chalks half an arch, leaves a lantern
burning, and is gone. The second reads the chalk, lifts the stone, and sets
it where the first one meant. Both chose. The arch stands.
